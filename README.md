## 🔬 M.Sc. research (manuscripts in preparation; code released on publication)

- **Alignment-free HIV-1 subtyping**: 10 subtypes, ~24k pol sequences, leakage-free grouped
  benchmark of 16 encodings × 3 CNNs vs linear baselines. A linear k-mer model is more robust
  than CNNs on short, clinical-length fragments.
- **HivGagFormer**: temporal Transformer on frozen ESM-2 embeddings for HIV-1 Gag substitution
  prediction; well calibrated (ECE 0.011 vs 0.318 for ESM-2 zero-shot).
